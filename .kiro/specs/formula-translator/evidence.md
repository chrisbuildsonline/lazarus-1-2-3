Reference words: KSBASE.WK1 writes relative columns sign-extended over bits 8..13 (`f5 bf` = -11,
`fb bf` = -5, `ff bf` = -1) and rows the same way (`01 80` = +1). testLotus123.wks writes relative
column -2 as `fe 80` and -1 as `ff 80`: bit 15 set, low 8 bits signed, bits 8..14 zero (no sign
extension). Both decode the same under the low-8-bit rule; only the reserved-bit check sees the difference.

The meaning of 0x0E, 0x14, 0x2F, 0x33, 0x3B, 0x52 and 0x58 above is inferred from cached values; the
opcode table cites a written reference for each before it is trusted.
