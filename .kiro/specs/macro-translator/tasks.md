# Tasks: Macro translator and approval queue (F10)

Red first: write each test and watch it fail before the code that makes it pass. Run `bun run test` and `bun run typecheck` after each task, `bun run build` and `CI=1 bun run e2e` after each task that touches `src/ui`, `src/workers`, `vite.config.ts` or `e2e/`. Files go in the paths from design.md, and test files mirror the source path (`src/macro/steps.ts` -> `tests/unit/macro/steps.test.ts`).
